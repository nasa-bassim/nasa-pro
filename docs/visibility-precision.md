# 가시성 경계 기반 계산

천체력 사이 고도·최단 방향 방위각을 선형 보간하고, 그 사이 통과하는 모든 지평선
격자에서 구간을 나눈다. 양 끝에서 모두 보여도 중간 능선이 가리는 경우를 찾는다.
각 조각의 가시 여유(el + 반지름 - 지평선) 영점으로 가시 구간을 구한다.
일조 비율·최장 암흑·동시 가시는 관찰 창에 잘라낸 구간 길이로 계산한다.
타임라인·최적 시작·오차 판정도 같은 구간을 사용한다. 시작 후보는 정시 단위다.
임무 임계값 판정은 반올림 전 비율을 사용한다.

## 실제 정밀 천체력

```bash
cd pipeline
uv run --frozen python -u -m pipeline.refine --site im-2
# Python 인증서 설정에 문제가 있고 시스템 curl은 정상인 경우
uv run --frozen python -u -m pipeline.refine --site im-2 --curl
```

원본 public/data는 보존하고 public/refined/<site>_<body>.json을 만든다.
평탄 지평선과 지형 모두 검사한다. 양 끝·중간·통과 지평선 격자를 검사하고 ±0.25°
근접/교차 구간과 이웃을 선택한다. 실제 Horizons 5분 자료로 재탐색한 뒤 1분 자료를
받는다. 요청은 직렬·캐시 처리하며 파일은 완성 후 교체한다.
웹은 좌표·천체·시간 범위·정렬·원본 시각 보존을 검증한다. 정밀 파일이 없거나 잘못됐으면
원본을 사용하며 현재 간격을 표시한다. 직접 좌표 및 주변 점 API는 아직 1시간 자료다.
0.25°는 선별용 경험적 여유이며 오차 보증이 아니다. 1분 간격도 이벤트 오차 1분을
보증하지 않는다. 샘플 사이 비선형 변화와 지형 격자 사이 작은 장애물은 놓칠 수 있다.
자료 범위 밖으로 외삽하지 않는 것이 계산 사용 계약이다.

## 정밀 지형

`pipeline/ice/terrain_fine.py`는 별도 rasterio/numpy/pyproj 환경을 사용한다.
[PGDA Site04](https://pgda.gsfc.nasa.gov/products/78)의 Site04_final_adj_5mpp_surf.tif를
pipeline/cache/lola/site04-5m.tif로, 기존 ldem_75s_240m.img도 같은 캐시에 준비한다.

```bash
pipeline/ice/.venv/bin/python pipeline/ice/terrain_fine.py
```

Shackleton Rim 중심점만 0.1° 지평선을 생성한다. 근거리 5m·20m 거리 간격과 원거리
240m 간격으로 250km까지 탐색한다. 달 GeoTIFF 좌표계·픽셀 중심을 사용한다.
지역 자료 밖은 광역 자료로 계산한다. 중심과 주변 오차 평가 점의 해상도는 다르다.
지형 변경 뒤 해당 지점의 pipeline.refine을 재실행해야 변경된 경계를 확인한다.
5m 격자가 5m 측정 정확도는 아니다. 관측점 사이 보간과 제품 경계 영향이 남는다.

## 실행 확인

IM-2의 실제 5분/1분 선택 구간 자료를 지형 반영 상태로 비교했다.
전체 기간의 태양 교차 15개·지구 교차 12개로 두 간격이 일치했다.
경계 시각의 최대 차이는 태양 약 0.032초, 지구 약 0.595초였다.
두 시간 간격 사이의 수치적 일관성 확인이며 실제 이벤트의 절대 오차가 아니다.
`web/src/lib/precision.test.ts`가 비교 진단값을 출력한다.
지형 오차를 전파한 시간 신뢰구간, 자동 수렴 보증, 장비 시뮬레이션은 미포함이다.
